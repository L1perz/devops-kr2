# Ревизия шаблона — вариант 3

Исходный шаблон: https://gitverse.ru/dgimatdinov/kr2-template

| Место в исходном шаблоне | Дефект | Последствие | Исправление |
|---|---|---|---|
| Dockerfile:1 | python:latest | При новой сборке может измениться версия Python и поведение приложения | python:3.12-slim, как в ПР №7 |
| Dockerfile:5–6 | Код копируется до установки зависимостей | Изменение app.py сбрасывает кэш слоя установки пакетов | Сначала requirements.txt и pip install, затем app.py |
| Dockerfile:5, нет .dockerignore | COPY . . включает .env и .git | Пароль и история репозитория могут попасть в слои образа | .dockerignore и явное копирование нужных файлов |
| .env отслеживается Git | Пароль опубликован в репозитории | Значение известно всем читателям истории | Удалить .env из текущей ветки, добавить .gitignore; создать новый пароль на сервере |
| Dockerfile, нет USER | Приложение работает от root | Уязвимость приложения даёт права root внутри контейнера | Отдельный пользователь app, UID 999 |
| Dockerfile:9 | Shell-форма CMD | Оболочка становится PID 1, завершение приложения по сигналу может задерживаться | Exec-форма CMD |
| Dockerfile:9 | Привязка к 127.0.0.1 внутри контейнера | Проброс порта не достигает слушающего сокета приложения | 0.0.0.0 внутри контейнера; 127.0.0.1 на сервере |
| Dockerfile:8–9 | Порт 8000 | Не соответствует варианту 3 | Порт 8003 |
| Dockerfile:6 | pip сохраняет кэш | Лишний расход места в образе | --no-cache-dir |

Исходная история main сохранена. Старый пароль нельзя повторно использовать, даже после удаления .env. Логика app.py и requirements.txt не изменена; добавлен только требуемый комментарий студента.

Статус: сборка, повторная сборка с кэшем, Compose, HTTPS и итоговый аудит проверены на Ubuntu VM. Реальные выводы сохранены локально в work/evidence.
